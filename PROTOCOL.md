# Frozen pilot protocol and proposed confirmatory study

Implementation defaults below are engineering choices, not calibrated on test labels. Freeze completed input manifests before scoring. This document is a protocol, not a claim that visual trials ran.

1. Use the deterministic 24-image subset in DATASET.md. Have an author inspect only images and write one general scene description, one detailed description and one clearly mismatched description per image (or homogeneous scene group). Store authorship and timestamp. No category annotations, model predictions or reference captions may be consulted. Detailed descriptions may name visible objects: report this as additional human semantic supervision. General descriptions should name a scene type without enumerating objects. Misleading prompts should name plausible but absent categories; independently audit them before evaluation. Current lexical interpreter will often leave general descriptions ineffective: that is a baseline limitation to measure.
2. Fixed local CLIP ViT-B/32, immutable Hugging Face commit recorded in manifest, CPU eval mode, seed 0, two threads, RGB bbox crops, default pinned processor, text template `a photo of a {category}`, 80-class vocabulary. No fine tuning. Same crops and score vectors reused in all four conditions. No prompt-driven candidate creation or vocabulary expansion.
3. Fuse cosine scores with a 0.02 bonus for literal category mentions, bounded maximum bonus 0.05. A label below visual cosine 0.18 cannot receive a context bonus. Abstain if winning visual score <0.18 or fused winner margin <0.02. These are uncalibrated heuristics; cosine evidence does not guarantee correctness or object existence. The floor can still admit a visually wrong label. Prompt negation is unsupported and may cause harmful bonuses. Evaluate this failure explicitly later.
4. Primary metric: accuracy = accepted correct / all candidates (abstention counts as no correct prediction). Also report accepted coverage, abstention, wrong-target risk = accepted incorrect / accepted, incorrect / all, and category-change rate relative to no context. Undefined denominators yield null. Here wrong-target risk is a proxy for wrong semantic assignment, not robot action or instance retrieval risk. Include class-balanced accuracy and per-size breakdowns in the confirmatory analysis.
5. Report shared image/text feature time separately from per-condition graph/postprocessing time. First-run loading/network time is included in shared time; distinguish warm/cold timing in subsequent trials. Record hardware, OS, dependency lock (`pip freeze`), model hash, manifests and all raw graphs. Runtime in the fixture is not model runtime.
6. near edges are undirected 2D normalized center-distance hypotheses with threshold 0.2 of image diagonal. No physical proximity guarantee, and no part_of assertion. Only compute relation precision/recall with separately authored exhaustive relation labels. Missing relation annotations are not negatives. Prompt-independent edges serve as a control; they cannot demonstrate a context benefit in relation inference.
7. Proposed confirmatory analysis: expand to at least 100 independent scenes after a held-out calibration set; choose sample size by desired confidence-interval precision using pilot scene variance. Freeze thresholds and context strength on calibration only. Compare paired per-scene accuracy differences with scene-cluster bootstrap 95% intervals (10,000 draws, fixed seed), not independent-region tests. Predeclare primary general-vs-none comparison; label detailed/misleading analyses secondary. Report harms, correct-to-wrong flips, wrong-to-correct flips and abstention transitions, including by class and prompt author. Repeat with shuffled prompts, negation, absent nouns, paraphrases, unknown classes and progressively inaccurate descriptions. Keep a zero-context-weight ablation and a contextual-text-embedding baseline.

Go/no-go: no Unity investment based on fixture results. Seek a positive held-out scene-level accuracy difference with uncertainty excluding zero, acceptable selective risk at matched coverage, and bounded degradation under misleading descriptions. Define application-specific acceptable risk before confirmatory evaluation. Failure is an informative thesis result; retain negative results unchanged.

## Executed pilot amendment (before evaluation; 2026-10-26)

The original literal-prior method is retained unchanged. A second, explicitly exploratory `contextual_text` method uses the same CLIP text encoder on `a photo of a {category}. Scene: {description}`. Unconditioned image features are identical. Decision score is baseline cosine plus 0.25 times the contextual-minus-baseline cosine, clipped to +/-0.05. Categories below the baseline visual floor receive no adjustment, and final acceptance requires the original visual floor as well as the fused margin. The fixed coefficient is not fitted to test labels. General/detailed/misleading conditions use identical coefficient and thresholds. The none condition is numerically identical between methods. This is an additional method comparison, not a replacement of an unsuccessful baseline.

Prompts were authored by the assistant from an image-only contact sheet, before category labels or predictions were inspected, then hashed in inputs/prompt_authorship.json. They are not independent human descriptions; some category words use synonyms/plurals that the literal parser misses. Misleading prompts intentionally mismatch scene types but need not have zero true object mentions. This small pilot is exploratory, with no statistical novelty claim. The primary scene-level statistic is the unweighted mean of per-scene paired accuracy differences; candidate-weighted accuracy is also reported. Bootstrap intervals are descriptive and unadjusted for multiple comparisons.

Inference and evaluation execute in separate CLI stages. The inference stage reads no truth file. COCO localization annotations define fixed proposals, an explicit oracle localization assumption. A separate small relation audit uses the first two eligible annotation IDs per image where possible, chosen before viewing model output. The assistant labels 2D apparent `near` from the displayed image regions, independently of numeric center distances. Ambiguous cases are marked uncertain and excluded. This audit is subjective, not public independently human-annotated semantic relation truth, and cannot validate physical proximity or part_of.
